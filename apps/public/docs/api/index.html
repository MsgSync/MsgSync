Authentication

Authenticate every request with a workspace API key. Use server-side storage and never expose keys in browser code.

HeaderRequiredValueNotes
AuthorizationYesBearer <api_key>Use a key from Developer Portal.
Idempotency-KeyRecommendedUnique request stringPrevents duplicate sends during retries.
X-Request-IDNoClient trace IDIncluded in logs and support traces.
curl https://api.msgsync.dev/v2/messages \ -H "Authorization: Bearer $MSGSYNC_API_KEY" \ -H "Content-Type: application/json"

Messages

POST /messages

Send a single SMS message to an E.164 destination.

ParameterTypeRequiredDescription
recipientstringYesDestination in E.164 format, e.g. +12025550194.
contentstringYesUTF-8 message content, subject to content policies.
metadataobjectNoCampaign context, profile, sender, and integration metadata.
metadata.profilestringNoTRANSACTIONAL, PROMOTIONAL, or OTP. Default: TRANSACTIONAL.
metadata.senderIdstringNoApproved alphanumeric sender ID or virtual number.
scheduledAtISO 8601NoFuture delivery time. The value must be UTC or include an offset.
callbackUrlURLNoPer-message delivery receipt callback.
POST /v2/messages
{
  "recipient": "+12025550194",
  "content": "Your verification code is 482913",
  "metadata": {
    "profile": "OTP",
    "senderId": "MSGSYNC"
  },
  "scheduledAt": "2026-09-25T10:00:00Z"
}

Rates & routing

GET /network/rates/:planId

List rates for a plan. Each rate includes country, prefix, MCC, MNC, network, profile, price per SMS, and status.

ProfileUse caseDefault behavior
TRANSACTIONALAlerts and service messagesUses transactional rate plan.
PROMOTIONALMarketing campaignsUses promotional rate plan.
OTPOne-time passcodesUses OTP rate plan when configured.

Routing evaluates exact MCC/MNC, then priority, then lowest cost. Use the Routing Rules API to configure priority and sender overrides.

Billing & balance

GET /organizations/:id

Returns balance, suspended, billing policy, rate plan, and organization settings.

Never negative. Debits that would make a balance negative are rejected. A balance of exactly zero sets suspended: true and blocks new delivery until credit is restored.

POST /organizations/:id/balance

ParameterTypeDescription
amountnumberPositive credit amount to add.
descriptionstringAudit description for the credit transaction.

Error codes

HTTPCodeMeaningAction
400VALIDATION_ERRORInvalid request parameter.Correct the request body or query.
401UNAUTHORIZEDMissing or invalid API key.Check Authorization header.
403BALANCE_EXHAUSTEDAccount is suspended at zero balance.Add credit before sending.
403CONTENT_REJECTED_URLBlocked URL detected.Remove or replace the URL.
403SENDER_NOT_ALLOWEDSender is not approved or allowed.Use an approved sender ID.
